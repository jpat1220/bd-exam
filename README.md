# bd-exam

## 📋 Descripción
Base de datos en **PostgreSQL** para gestionar usuarios, servicios y turnos.

## ⚙️ Requisitos
- PostgreSQL 14
- Cliente SQL (pgAdmin)

## 📂 Tablas principales
- **tipo_usuario:** Define los tipos de usuario (Cliente, Empleado, Proveedor)  
- **ciudad:** Contiene las ciudades registradas  
- **usuario:** Información general de los usuarios  
- **servicio:** Servicios ofrecidos  
- **turno:** Turnos asignados a los usuarios  

---
Para visualizar datos:
SELECT * FROM usuario;
